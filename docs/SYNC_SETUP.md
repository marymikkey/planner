# Синхронизация между устройствами (Supabase)

Синхронизация необязательна и по умолчанию выключена. Она работает через **ваш собственный** бесплатный проект Supabase. Приложение шифрует каждую запись на устройстве (AES-GCM-256, ключ из вашей парольной фразы через PBKDF2) до отправки: Supabase видит только шифртекст и служебные поля (тип записи, id, время изменения, пометка «удалено»).

Конфликты решаются правилом «последняя правка выигрывает» для каждой записи. Удаления тоже синхронизируются. Без сети приложение работает как обычно и догоняет при появлении интернета, при возврате в приложение и раз в минуту.

С устройства на устройство едут все данные и настройки раздела (рабочий день, валюта, цвета, категории, бюджет…). Тема и язык остаются своими на каждом устройстве.

## Один раз: создать проект (≈5 минут)

1. Зарегистрируйтесь на https://supabase.com и нажмите **New project** (план Free). Запомните пароль базы — он для этого приложения не нужен.
2. **SQL Editor → New query**: вставьте SQL из приложения (Настройки → Синхронизация → «SQL для проекта Supabase» → «Скопировать SQL») или из файла `js/core/sync.js` (константа `SETUP_SQL`) и нажмите **Run**.
3. **Authentication → Sign In / Providers → Email**: выключите **Confirm email** (для личного проекта так проще).
4. **Project Settings → API** (или «Connect»): скопируйте **Project URL** (`https://xxxx.supabase.co`) и **anon / publishable key**. Этот ключ публичный по дизайну: данные защищены правилами доступа (RLS) и шифрованием.

## Подключить первое устройство (ноутбук)

Настройки → Синхронизация: вставьте URL и ключ, придумайте email и пароль аккаунта, придумайте **парольную фразу шифрования** → «Создать аккаунт и подключить». Нажмите «Скопировать код подключения».

## Подключить второе устройство (iPhone)

Отправьте себе код подключения (заметки, мессенджер). На iPhone: Настройки → Синхронизация → вставьте код (URL и ключ подставятся), тот же email и пароль, **та же парольная фраза** → «Войти и подключить».

После этого (по желанию) в Supabase отключите регистрацию новых пользователей: Authentication → Sign In / Providers → выключить «Allow new users to sign up».

## Важно

- **Парольную фразу нельзя восстановить.** Забудете — облачную копию не расшифровать (локальные данные на устройствах останутся; можно отключить синхронизацию, сделать экспорт JSON и начать заново).
- Бесплатные проекты Supabase «засыпают» после недели без активности; их можно разбудить в панели управления.
- Не включайте синхронизацию при демо-данных: они попадут в облако. Приложение это блокирует.
- «Сбросить все данные» при включённой синхронизации удаляет данные и в облаке, на всех устройствах.
- Рекомендуется иногда делать «Экспорт JSON» как резервную копию.
